# AIRI-035：人物与智能体共用本地聊天档案

日期：2026-10-09。状态：采用。

用户需要长期记忆页中轻量的聊天档案，并希望角色能回看自己与不同人物的交流。采用既有 Vue/Pinia 界面、会话仓库和模型工具接口，不引入独立聊天后台或外部账户。

档案按账户 ID 与智能体 ID 组织，跨会话呈现原文。整理独立关联原消息；日期缺失明确显示未知。页面和模型访问同一持久服务，页面卸载不影响检索。本人开放，其他人物浏览复用开发者鉴权；模型工具只访问当前关系。身份或角色变化会拒绝旧异步结果。

普通模型与慢脑提供查关系、搜索、展开原文、整理四类工具。快脑引用少量历史并通过后台任务委托深入查询。回顾有字符预算，所有历史和整理作为引用数据；不将其视为系统命令。删除由用户确认，原文与整理一并清理，模型没有删除权限。

代价：底层沿用整会话存储，界面分页并非数据库分页；浏览器来源隔离，未实现跨设备汇总。第一版提供关键词检索及人工/工具摘要，没有向量搜索、自动会话总结或模型训练。后续性能优化须保留来源引用、权限检查与删除语义。主机 SQLite 的人物交流记忆保持原职责，不复制为第二份完整聊天原文。
