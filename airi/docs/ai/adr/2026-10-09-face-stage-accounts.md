# 人脸关联舞台本地账户

日期：2026-10-09。任务：AIRI-034。状态：采用。

## 问题

视觉系统已有持久人物档案，舞台账户显示仍来自 hosted 登录状态。
只改姓名会让不同人物共用访客历史。直接改 auth 会把识别结果误当作云端授权。
现有会话切换重启采集，接到账户后会形成身份丢失与反复退出的循环。

## 决策

新增共享 stage-identity，使用现有确认人物 ID 选择本地会话分区，姓名只负责显示。
采集拥有者发布身份租期。新鲜单人确认、人脸、姓名和观察权限共同控制进入身份。
多人、姓名纠错、撤权、离开、停机和租期到期回到陌生人。
Web 摄像头账户模式不修改 hosted auth，也不进入云同步。

账户和会话变化移动视觉投影，保留摄像头。角色变化仍重新采集。
旧生成、语音和慢脑结果核对账户与会话边界，新身份由原有自动语音宿主接管。
身份状态跨窗口同步，不同步原图、模板或人物记忆。浏览器历史继续按来源保存。

## 影响与限制

改名保留聊天分区，重遇能恢复自己的会话。未建档的人继续用原姓名确认和建档流程。
最多两秒租期限制断帧后的旧姓名。误识别仍取决于既有识别模型，租期不证明模型准确。
本地账户不构成高保证生物认证，不开放开发者管理、云权益或跨设备共享。
这次自动验证使用合成采集、生成身份、模拟模型和本机测试 WebSocket。
真人准确率、物理进出和真实模型回答需要现场验收。
