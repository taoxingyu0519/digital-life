## 角色如何搜索

后续变更：用户报告403后，AIRI-020替代了下述浏览器直接匿名请求方案，改用本机官方CLI网关，并增加可选Free账户Key与注册入口。本文保留AIRI-018当时的结果；当前实现见[403修复报告](2026-10-03-firecrawl-403-fix.md)。

原有 `web_search` 工具现在可以选择 Firecrawl 或 Tavily。
Firecrawl 会向官方 `https://api.firecrawl.dev/v2/search` 发起真实请求。
当前不发送账户密钥，只使用 `web` 网页来源，每次最多十条结果。
不附加网页抓取，不调用收费数据供应商，不自动重试额度错误，也不回退到其他服务。
Tavily 保留原来的独立密钥设置。

普通聊天和慢脑使用同一个搜索工具。
慢脑先取得可用工具，再组合相应的系统提示，保证第一次请求也有搜索工具使用说明。
是否搜索由模型通过函数调用决定。
项目没有根据问题关键词伪造搜索活动。

真实工具返回有长度限制的网页摘要、来源网址、请求 ID 和服务端报告的消耗。
网页文字作为外部数据处理，不能变成系统指令。
快脑通过已有任务运行时接收慢脑确认的结果和证据。

搜索总开关默认关闭，设置独立保存在当前浏览器域名下。
设置页的“测试搜索”会查询公开价格页，并显示真实回执。
仅仅打开开关不代表已经联网成功。
回执只保存在内存，刷新页面后会消失。

## 免费额度的实际边界

[官方价格页](https://www.firecrawl.dev/pricing)写明：免费账户每月有 1,000 credits，不要求银行卡。
普通搜索每十个结果消耗两个 credits。
[官方接入说明](https://www.firecrawl.dev/agent-onboarding/SKILL.md)也提供无需密钥的匿名免费搜索，但限额更低。

本次接入使用匿名免费入口。
没有绑定免费账户，因此不能声称已经获得账户的每月 1,000 credits，也无法读取剩余额度。
界面明确说明了这个区别。
遇到 HTTP 402 或 429 时，本次调用结束并显示真实错误。
项目不会自动升级账户或转用付费服务。

官方技能建议提交搜索反馈。
本次针对公开价格页尝试反馈时，命令行工具要求登录。
没有完成登录、反馈提交、退款或账单变更。

## “真实 DeepSeek 与语音完整链路”是什么意思

它指实际跑完下面这一轮：

1. 用户在语音通话中提出需要查询的问题。
2. 豆包快脑受理请求，把任务交给慢脑，同时继续听用户说话。
3. 用户配置的 DeepSeek 实际收到任务，并决定调用 `web_search`。
4. 项目执行 Firecrawl 查询，把真实来源和结果交回 DeepSeek。
5. DeepSeek 整理结果，项目把结果送入共享上下文。
6. 豆包在合适的空隙说出结果，用户在自己的设备上实际听到。

还要检查用户中途说话、修改要求或打断时，旧结果是否正确取消，是否会抢话。
完整链路同时涉及真实模型服务、工具调用、快慢脑协作和麦克风与扬声器。

**目前真实搜索接口已经验证成功，程序协作流程也通过自动测试。**
**尚未用用户配置的 DeepSeek 和实际豆包语音通话，把上面六步完整跑一遍。**
因此，“完整链路尚未验收”不表示已经发现故障，也不表示搜索是假结果。
它表示还没有取得整轮实际模型与语音往返成功的证据。
自动测试中的模拟模型返回，不能当作真实 DeepSeek 服务已经成功查询和播报。
这部分实际服务、延迟和语音体验继续由 AIRI-004 跟踪。
