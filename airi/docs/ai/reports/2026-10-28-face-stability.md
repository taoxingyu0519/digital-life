# 人脸稳定与每秒一次采集交付报告

日期：2026-10-28（Asia/Shanghai）。任务：AIRI-044。分支：`codex/feat/face-stability`。

## 结果

前端舞台现在每秒最多发送一帧进行本地视觉推理。短时分数波动采用固定参考核验，减少已确认人物反复回到陌生人引起的账户和聊天会话切换。
完整交付门禁已通过，实际舞台启停及休眠导航已验证。当前浏览器未发现摄像头，真人稳定性尚未验收。

## 已证实的原因

1. `LocalVisionCapture` 原循环每67ms尝试发送一帧，只有服务繁忙时才自然降速。
2. 首次确认需两秒内三次匹配。每秒采样加少量编码或传输抖动，第三次到来时第一条已经出窗。
3. 单次图库分数跌破保持门槛就撤销人物，之后又需要重新收集确认。账户状态的切换会取消旧工作并重选聊天会话。
4. 同人租期按新增1000ms才续约，一秒采样叠加延迟变化时余量不足。
5. 目光500ms时效和补采0.8秒最大帧间隔不能覆盖一秒采样周期。

## 实现与边界

| 范围 | 新行为 |
| --- | --- |
| 前端送检 | 两次循环至少间隔1000ms，单帧在途、拥塞保护和停止栅栏保留，繁忙时不补发队列。摄像头预览独立运行 |
| 首次确认 | 3.5秒窗口内三次独立一致候选，相邻有效样本最多1.5秒，原相似度与候选差不变。候选换人重新计数 |
| 短期参考 | 来自图库独立支持的确认帧，仅保存在本机worker内存。当前仍为同一唯一候选、连续单人轨迹且参考余弦至少0.80，才桥接分数下降 |
| 保持期限 | 固定参考和短时模糊最多2.5秒。弱帧不更新参考时间、不登记、不写社交样本。丢失、多人、身份冲突、身体框跳变、重置清空参考 |
| 账户租期 | 观察有效期仍最多两秒，近到期时预留1.2秒等待下一帧，过滤重复观察带来的毫秒抖动。断帧独立过期 |
| 目光 | 含往返画面年龄最多1500ms且不超过观察租期，避免每秒回中一次。检测明确失脸仍保留原250ms短保持 |
| 基础补采 | 最大帧间隔1.5秒，前后三次基础复核窗口3.5秒，保留原质量、邻接特征、12秒轮次和可撤销扩展规则 |

没有更换模型、增加SDK或外部服务，没有登记或删除真实人物资料。
这些时间和0.80阈值属于保守工程参数，未用独立真人录像标定误认率。
本轮沿用本机YuNet、EdgeFace及ByteTrack，首次匹配门槛不变。

## 未验收

当前浏览器明确报告未发现摄像头。本轮没有采集真人图片或录音，没有发起真实模型对话。
笔记本摄像头下的侧脸、逆光、遮挡、多人交换、长时误认率、CPU/GPU功耗与真实语音听感仍分别由AIRI-009/AIRI-004验收。
送检降为1Hz后，新人物首次确认通常需要约两秒，画面变化最多等待下一次采样。真实网络延迟需现场测量。

## 资料与后续入口

[CAFace论文](https://arxiv.org/abs/2210.10864)研究质量不一的多图特征融合。本轮没有部署CAFace网络，固定参考与时间门控是本项目工程实现。
