# Firecrawl 403修复与免费账户入口

日期：2026-10-03。任务：AIRI-020。所有结论区分真实搜索、模拟上游回归和未配置服务。

## 查明的问题

用户报告设置按钮、语音和文字搜索均失败，文字模型连续三次调用web_search收到403。共享工具的旧实现从浏览器直接匿名POST官方/v2/search，没有Firecrawl账户Key入口，并丢弃错误响应正文，只显示状态码。这会让模型无法区分权限问题、限额和网络异常。

本轮主机上的公开REST查询返回200；官方CLI也返回了南宁天气来源。修复前浏览器按钮复现的是15秒超时，未取得用户先前403的响应正文。因此不能断言那次403具体来自IP限制、匿名额度、WAF或账户权限。已经确认的是接入方式与错误诊断存在问题，不是已有证据证明整台电脑断网。

[官方匿名接入说明](https://www.firecrawl.dev/agent-onboarding/SKILL.md)将无需Key的免费入口用于官方CLI、SDK和MCP，并说明限额较低。本轮让主机运行已安装的官方CLI，不手工伪造其客户端标识，也不绕过厂商权限。

## 当前真实链路

```text
文字聊天或语音慢脑实际发出web_search
  → 浏览器同源POST /api/web-search/firecrawl
  → 主机网关
      留空Key：执行官方CLI的匿名免费搜索
      填写Key：经官方REST使用该Firecrawl账户
  → 真实来源、请求ID与服务端消耗
  → 慢脑整理结果和证据
  → 普通文字回复；语音任务则交豆包快脑等空隙表达
```

模型决定是否调用工具。没有天气关键词路由、固定天气答案、虚构搜索成功或伪造余额。网页摘要是来源内容，可能陈旧；找到天气网页不能直接证明已经核对了当前温度或湿度。

共享工具保留脱敏后的服务端拒绝原因。实际401/402/403/429/503后暂停后续模型请求，修改配置或手动测试可恢复。说明约束模型停止换词重复调用，不把服务错误说成整个设备无法联网。配置变化使旧工具失效，迟到结果、错误和余额不能认证或阻断新配置。

网关只接受本地同源、固定搜索/余额路径，限制输入、并发和超时，用户取消时中止上游。只转发显式Firecrawl凭据与内容类型，不转发Cookie、LAN票据或模型指定URL。匿名调用检测环境和已保存CLI凭据，避免自动复用收费账户；账户调用不会改写CLI凭据。

## 注册与免费额度

“设置 → 网络搜索”提供“注册或登录Firecrawl免费账户”和“打开控制台获取API Key”。注册后选择Free套餐，复制Key填到独立Firecrawl输入框，再点测试搜索。Key只保存在当前浏览器，与Tavily分开，不写任务或文档。

[官方价格页](https://www.firecrawl.dev/pricing)说明Free每月1,000 credits、无需银行卡，普通搜索每10个结果消耗2 credits。匿名不是账户月额度；测试中实际消耗以服务端回执为准。

“查询账户剩余额度”调用[官方额度接口](https://docs.firecrawl.dev/api-reference/endpoint/credit-usage)，展示remainingCredits和planCredits。没有用户账户Key时不能读取真实账户余额。此接口不返回明确的套餐或自动充值状态，不能据数字宣称已验证Free套餐。用户应在控制台选择Free并保持付费与自动充值关闭；应用不升级或充值，也不转入其他付费服务。本轮未注册账号或接受条款。
