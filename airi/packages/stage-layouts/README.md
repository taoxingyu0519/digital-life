# Stage Layouts

## 职责

提供舞台、设置页和桌面/移动端的共享布局。Web、Electron 与移动客户端复用这些布局。
业务状态由 stage-ui 提供，布局负责组合和交互入口。

## 使用

通过 `@proj-airi/stage-layouts` 导入布局和组件。保留各客户端既有路由和设备权限入口。
主舞台的 InteractiveArea 把已保存历史及本次通话字幕传给 ChatHistory。
桌面聊天标题栏与移动端顶部提供 Aa 阅读控件，字号和气泡偏好由 stage-ui 本地设置保存。

## 适用范围

新增跨客户端的页面框架和舞台入口时使用本包。
单个业务场景放在 stage-ui，基础按钮或弹层放在 ui。模型调用、数据库写入和转写确认由对应 store 负责。

## 验证

修改共享布局后运行本包及根级类型检查，并验证桌面、移动端实际页面。
主舞台更改还需运行工作区的 `scripts/test-airi-delivery.ps1`，保留启停、身份与聊天回归。
