# 项目管理与目录同步

AIRI-046起，漏记录报告区分上游转写、消息ID关联、持久化和界面可见性；字幕可见不代表音频已送达。记录生成数据复现与真实页面验收，不把未保存且无原文的历史片段猜测补写。阅读偏好属于本浏览器，须注明与共享配置、人物记忆的边界。

AIRI-039：配置同步的浏览器及加密宿主回归已加入固定交付门禁。后续修改继续保留离线刷新、旧版本冲突、上传途中编辑、角色卡/登录恢复和多窗口责任归属；真实笔记本 SSH 现场与台式机双来源模拟分别记录。任务和报告只写同步 revision、配置存在与安全结果，不记录配置正文、模型密钥、登录令牌或浏览器备份内容。

## 打开与停止

双击工作区根目录的 [manage-project.cmd](../manage-project.cmd)，打开 [本地工作台](http://127.0.0.1:5174)。
双击 [start-airi.cmd](../start-airi.cmd) 也会启动它。管理服务在后台运行，关闭浏览器不影响目录同步。
仅监听 `127.0.0.1:5174`，没有外部账号和网络服务依赖。电脑重启后需重新运行启动器。

笔记本测试使用 [连接指南](08-lan-testing.md) 中的 LAN/UU SSH 入口。
远程恢复调用 `scripts/start-airi-background.ps1`，私人访问凭据不写入任务记录。项目管理仍在主机操作。
网络入口检查与笔记本真实设备验收分别记录在任务中。

停止管理工具与目录同步：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\stop-project-manager.ps1
```

## 日常开发流程

AIRI-045 起，任务记录须区分“登录账户”“当前归档人物”和“主舞台会话”。不得用人脸人物 ID 当作认证或声称发生登录。记录逐消息归档、匿名 ID 保留、姓名确认与混合会话删除的验证，不记录真实人物姓名和私人聊天。自动测试保留原识别/语音/会话/归档场景，原来要求随人脸换会话的断言按新产品要求改为连续会话断言，不删除场景。

1. 新建任务，写明目标与验收条件。点击任务卡可修改标题、说明及状态。
2. 开始开发时改为“进行中”。状态有待办、进行中、已完成、待处理四种。
3. 完成应用代码后运行 `scripts/test-airi-delivery.ps1 -Task <任务编号>`，保留旧功能固定基线。失败不得记录“回归通过”；修复后重新运行受影响检查及门禁。涉及模块职责、数据流或接口变化时，更新架构说明和开发指南。
4. 保存任务时写本次变更说明。状态和说明会自动追加到变更记录，并同步目录。
5. 交付前点“立即同步目录”，确认同步成功。

记录至少包含：当前变更、自动检查结果及日志位置、实际启动/关闭/再启动和设置/长期记忆导航的观察，以及真实模型/麦克风/摄像头未具备的边界。自动 `result.json` 只证明本次自动检查；人工/设备验收另记，不能把“配置存在”写成“模型鉴权和音质通过”。原问题的复现测试须留在回归基线，以后每次修改继续执行。任务完成前还要运行 Wiki check 并记录无待复核/无错误，机械目录同步不能替代这些检查。

AIRI-042 将人物全部记忆清除、多窗口撤销与真实存储清理加入固定基线。删除验证使用生成数据，任务记录只写验证范围和结果，不写被删除人物的真实姓名、正文或照片。清理跨主机/浏览器时分别记录边界，不把单处删除当作全设备遗忘。

任务数据为 [tasks.json](../项目管理/tasks.json)。每次写入前，旧版保存在 `项目管理/tasks.backup.json`。
保存采用临时文件加原子替换；多窗口编辑遇到版本冲突时会要求刷新，不覆盖别人刚保存的内容。
也会生成可直接阅读的 [看板](../项目管理/看板.md) 和 [变更记录](../项目管理/变更记录.md)。
工具没有永久删除入口；过时任务可修改说明后保留记录。

如需恢复任务数据，先停止管理工具，备份当前 `tasks.json`，再将 `tasks.backup.json` 复制为 `tasks.json`，重新启动。
管理工具不能替代 Git 或整机备份。源码仍在 `airi` Git 仓库内；提交源码时，也应另行备份仓库外的文档和任务数据。

## 自动更新的范围

服务每 5 秒使用 Git 忽略规则扫描源码文件的大小和修改时间。检测到变化后运行索引生成器。
新增、修改、删除、重命名和切换提交都会触发更新；已修改文件的后续编辑也能识别。
自动生成包索引、依赖 JSON、三层目录树、当前文件清单和 Git 改动列表。未提交新文件纳入索引；`node_modules` 等忽略目录不纳入。
工作区完整文件索引还包含 `scripts/`、根目录文档与启动器、人工维护的开发文档和任务数据。修改这些文件也会触发同步。

“同步成功”表示上述机械索引已更新，**不表示架构分析已自动重新撰写**。
工作区 [AGENTS.md](../AGENTS.md) 规定后续开发要维护架构说明、开发指南、任务与变更记录。
如果使用不读取该文件的工具，或手动改动业务逻辑，请按上面的日常流程补充说明。

服务关闭时可手动同步：

```powershell
. .\scripts\airi-env.ps1
& $AiriNode .\scripts\generate-project-index.mjs
```

仅修改国际化源文件不会改变已构建的文案包。请运行：

```powershell
. .\scripts\airi-env.ps1
Set-Location $AiriRepo
& $AiriNode $AiriPnpm --filter '@proj-airi/i18n' build
```

## 陌生人模式

Web 默认进入角色舞台。未登录时显示“陌生人”，点击可配置自己的模型服务。
每次请求根据当前认证状态产生身份上下文，中文访客称呼为“陌生人”；英文为“Stranger”。
访客保持未认证状态，数据继续使用原有本地存储身份 `local`；不会创建假账号或令牌。
退出真实账号后，下次请求恢复访客上下文，不继续注入原账号姓名。

免 AIRI 账号可使用本地对话、角色、历史及已配置的语音能力。实际回答仍需要可用模型。
官方云同步、官方模型额度、兑换及账号资料仍需要官方账号。要替换这些服务，需另做自托管后端开发。
当前没有替用户配置 API Key、下载大语言模型权重或完成真实模型语音对话。

## 视觉模块任务记录

视觉任务同时记录工程变更和实际证据，不能用“已出现按钮”替代模型推理验证。
`AIRI-008` 记录本地服务、协议、正式 UI 和对话接入。
`AIRI-011` 记录默认持续视觉、主动／被动模式、对话自然建档、多角度照片与记忆闲聊。
`AIRI-014` 记录非商业科研用途、质量选帧、多帧证据、降频、轻量模型对比和保留旧档案的独立索引。
`AIRI-015` 记录人脸目光与头部跟随，区分本地位置、浏览器渲染接线与真人方向/延迟验收。
最新用户要求取代原方案的默认关闭与强制手工登记。不要把可选质量校准写成用户使用前置条件。
未完成的真人身份质量、摄像头、真实 API、完整性能与扩展模型验证继续由 `AIRI-009` 跟踪。
代码完成不等于用户现场功能验收。任务记录分别写清模型配置、设备可用性和实际测试证据。

每次验证记录命令、退出状态、证据文件和测试方式：单元、合成帧、真人现场或授权回放。
报告放在 `airi/services/local-vision/reports/`；原模型和私人数据留在忽略目录。
只允许将模型 hash、版本和脱敏统计写入台账。不得记录模板、照片、API Key 或服务凭据。
修复真实人物档案前保存可恢复的本地数据库备份，台账只写数量与原因，不写真实姓名或人物 ID。
用户现场反馈与自动测试分开记录。模型调研的论文指标不能记作本机准确率、耗电或稳定性验收。
摄像头统计没有实际连接时，记录“未取得现场样本”，不能把零跳变解释为识别稳定。
运行 `vision.ps1 accept` 后仍有 NOT_RUN 或 BLOCKED 项时，不得写“全部验收通过”。
新增本地脚本和文档后仍需执行目录同步，人工架构说明继续独立维护。

## Wiki 与开发记忆

本项目交付、验证和调查报告统一使用中文，这是用户在AIRI-019明确的长期要求。
保留技术名称、代码、命令、路径和原始错误，不翻译程序标识符。必要时补中文解释。
报告把真实服务结果、模拟测试和未验收范围分别写清，不用“完整链路”等术语省略实际验证内容。

快慢脑改动由 `AIRI-016` 记录代码、文字入口、前端任务面板、协议/浏览器测试及文档。
`AIRI-004` 继续记录真实豆包与慢脑服务、音色/FC权限、设备往返及体验验收。
“慢脑模型已选择”仅代表配置；“后台工具轮次测试通过”使用模拟服务，不能写成真实服务已通过。
任务需要保留命令、退出状态和报告路径，不记录Key、用户私人发言或原始数据库结果。

本地工作台新增项目管理 Wiki。输入问题可查找最多五篇专题，点击目录可逐层阅读。
正文中的已登记源码链接可查看文本证据。管理界面只读 Wiki，编辑通过工作区文件完成。
[Wiki 首页](../wiki/README.md) 同时是 Codex 新对话的入口，工作区 AGENTS 已接入此规则。

Wiki 记录当前职责、算法、数据流、成长历史、设计决策和可复用经验。
每轮开发更新相关专题，使用 [开发记录模板](../wiki/templates/session.md) 保存目标、验证与交接。
任务仍是进度账本，Wiki 不替代 tasks.json，也不抄录全部任务事件。

目录同步扫描 Wiki 人工文件，生成目录和来源指纹状态。
已核对只表示文件与人工核对记录一致，不表示真人验收或模型服务已配置。
正文、源码或 catalog 条目变化后显示待复核。新条目缺少指纹时显示未核对。
自动同步不更新人工基线。开发者读过相关变化后用 review 记录本轮核对。
交付前运行 `project-wiki.mjs check`，把实际结果和未验收范围写入任务。

Wiki 与任务同属 airi 仓库外的工作区文件，提交 airi 时另行备份这些资料。
人物记忆、照片、姓名、模板、Key 和私人测试入口不得写入 Wiki。
详细流程见 [维护说明](../wiki/maintenance.md)，当前实现见 [数据与记忆](../wiki/modules/storage-memory.md)。

## 运行时记忆维护的记录边界

AIRI-025 的开发者界面管理角色运行时 SQLite，与项目任务和 Wiki 分开。
任务只记录脱敏改动、命令结果和验收边界，不记录密码、摘要、Cookie 或真人姓名。
验证页面使用生成档案，真实数据库先备份到私密目录。代码完成与真人纠错体验分开记录。
本机开发者账号不授予项目管理工具、hosted 账号或付费服务额外权限。

AIRI-035 的聊天档案验证记录只使用生成消息与模拟外部模型接口。任务需区分原生持久化/权限测试、真实请求序列化、模拟工具结果与真实模型验收；不把用户私人聊天、导出内容或整理摘要放入任务和 Wiki。
