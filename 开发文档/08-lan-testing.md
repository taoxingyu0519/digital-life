## 2. 主机启动

双击工作区的 [start-airi-lan.cmd](../start-airi-lan.cmd)。
它检查现有 Web、视觉服务和 LAN 网关，启动缺少的进程，并显示私人测试链接。
主机保持开机，笔记本连接同一家庭网络。
本次已经放行 Node 的 5442、5443 入站端口，仅限专用网络 `192.168.1.0/24`。
Web、Python 视觉服务和项目管理继续监听回环地址，分别使用 5173、18765、5174。
证书页面只提供公开证书和安装步骤，不提供私人测试链接。
主机 IP 变化时，更新启动地址、证书和对应防火墙规则。

这些进程目前不作为 Windows 开机服务注册。主机重启或进程停止后，需要在主机重新运行
`start-airi-lan.cmd`，再打开原来的私人测试链接。该启动入口可重复运行，会复用现有证书和访问凭据。
链接无法连接时，先检查 5443 网关与 5173 网页是否监听；证书说明页面 5442 也打不开时，
优先检查主机服务、地址和网络。已有证书未改变时，无需让笔记本再次安装证书。

现有 SSH 隧道仍可作为备用方式。需要已登记的 SSH 密钥。
`connect-airi-laptop.cmd` 在笔记本运行后，备用浏览器地址为 `http://127.0.0.1:5173`。
直接使用 `http://192.168.1.5:5173` 会因缺少安全上下文而白屏。

## 4. 安全边界和实现

`scripts/lan-gateway.mjs` 是局域网入口。它先检查精确 Host、访问 Cookie 和 Origin，再转发 HTTP 与 WebSocket。
认证成功后，它把请求转为受信任的回环请求。原语音、视觉网关继续保管真实凭据并校验协议。
跨站来源、未知 Host、缺少私人链接的请求返回 403。
TLS 私钥、访问凭据保存在忽略目录 `airi/.local/lan`，Vite 禁止直接、raw 和 import 读取。
摄像头短期一次性票据仍由 Python 服务签发。客户端以 POST 申请票据。
前端按浏览器安全上下文允许视觉启动，不再用 localhost 主机名拒绝已信任的局域网 HTTPS。
“占用视觉”只表示浏览器窗口采集归属或其他本地视觉任务冲突。
更新前端后，在笔记本按 Ctrl+F5 刷新。若仍显示占用，保留一个测试标签页并关闭其他采集任务。
Vite 将同源帧 WebSocket 转发至 Python，不向笔记本暴露长期视觉服务凭据。
没有新增外部账号、付费服务或依赖。

## 6. 当前 LAN/UU 连接助手（2026-10-08）

笔记本始终打开 `http://127.0.0.1:5173/`，连接窗口保持运行。
LAN SSH 目标为主机当前家庭地址 `192.168.1.2:22`。
公司或其他外网通过 UU 映射：笔记本 `127.0.0.1:22022` → 台式机 `127.0.0.1:22`。
保留既有密钥、known_hosts 和 `stardream` 配置别名，不关闭主机公钥校验。
助手依赖笔记本既有连接目录中的 `ssh_config` 与 `ssh_config_uu`。
下载包不包含私钥或这些个人配置，复制修正版时由笔记本 Codex 核对本机路径。

外层 UU 提供到台式机 SSH 的网络通道，内层 SSH 转发主机回环 Web 与视觉服务。
原视觉客户端帧实际走 Web 同源 WS，18765 转发保留给现有助手的端口诊断。
网页、语音与摄像头控制仍沿用原模型鉴权、浏览器设备权限和开发者会话。
浏览器回环地址提供安全上下文，这条隧道无需安装旧家庭 IP 的 HTTPS 证书。
家庭 IP 改变时更新 LAN 配置，UU 回环目标保持不变。
主机关机、断网或公司网络阻断 UU 时，此入口不能保证连接。

台式机缺失服务由 `scripts/start-airi-background.ps1` 恢复。
它复用健康服务，后台启动缺失 Web，记录进程，再核对同源视觉健康。
不要在远程命令中同步等待前台 `start-airi.ps1`，否则长驻 Vite 会阻止状态回执并造成超时。
不健康的已占用 Web 端口会报告错误，不结束未知程序。

本轮复核：台式机回环 SSH 握手恢复，8 项助手行为检查通过，修正版只读服务回执为
`webHealthy=true`、`visionReady=true`，后台启动入口复用健康服务时正常返回。
用户转回公司现场 SSH 握手、公钥校验、Administrator 登录、网页 HTTP 200 和视觉 ready 成功。
本轮未强行停止旧时间记录不符的 Web，故缺失 Web 冷启动分支未完成现场验证。
15 项本地回归来自笔记本此前报告，测试文件未随包提供，本轮未重复执行。
家庭 LAN 连通性、笔记本摄像头和麦克风、真实模型通话仍须现场验收。
