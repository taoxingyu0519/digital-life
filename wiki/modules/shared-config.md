# 跨设备配置同步

AIRI-046 的字号和气泡大小是当前浏览器偏好，键为 `settings/chat/font-size` 与 `settings/chat/bubble-size`。它们不进入台式机共享模型配置、人物记忆或提示词；换浏览器可独立调整。恢复默认写回18px和标准气泡，不回到本次加载时的旧保存值。

2026-10-12，AIRI-039。入口：Web 设置 → 配置同步。用于笔记本、台式机和不同回环端口共享同一智能体配置。

## 原因与落点

旧实现把快慢脑提示词、慢脑选择和服务配置保存在浏览器来源的 localStorage。即使网页来自同一台式机，笔记本 `127.0.0.1:4173` 与旧地址/其他浏览器仍是不同来源。用户提供的连接助手说明确认了固定入口改为4173；新来源读不到旧来源不等于旧数据已删除，本轮未直接读取笔记本旧存储。

当前 Web 通过同源 `/api/shared-settings` 读取和提交台式机统一副本。该请求穿过现有 SSH 转发，与模型/视觉网关使用同一网页入口，不修改连接脚本、SSH 鉴权或主机公钥。台式机存储为 `airi/.local/shared-settings.bin`，整个内容用当前 Windows 用户的 DPAPI 加密；保留上个加密版本。浏览器缓存、离线检查点和本机替换前备份仍在各自来源，页面只显示状态、版本和备份时间。

## 共享范围与责任

共享快脑/慢脑/结果/续聊等规则、慢脑模型与采样/思考参数、用户添加的模型服务配置、会话风格/等待时间/文字入口开关及联网搜索配置。模型服务密钥随配置同步，不写入版本控制、任务、日志或截图。

摄像头/麦克风权限和设备选择、浏览器语音识别适配器、运行/休眠、hosted 登录、聊天档案和人物身份沿用原落点。实时语音模型与音色/Key 原本由台式机网关统一保存。人脸账户不是此共享配置的权限或登录凭据。Web 是本轮接入客户端；Electron、Pocket 和旧 LAN HTTPS 尚未接入。

同一浏览器由 Pinia 领导窗口负责宿主 IO，跟随窗口通过既有同步 action 交给领导窗口。跨来源/设备由宿主 revision 协调，保存去抖约750ms，读取间隔5秒。原始登录检查继续由原服务执行，不传递 hosted 认证 provider。远端配置应用前结束旧实时工作，按 provider→model 的顺序更新，并把模型写入当前角色卡，避免重载旧卡覆盖选择；登录默认值后恢复用户慢脑选择。

## 断线、冲突与迁移

未同步编辑和基准 revision 持久化，刷新及重新选主会重读检查点。提交采用 CAS；另一设备先保存后，旧版本不能覆盖它。页面显示冲突，用户选择台式机最新版或保留本机配置并同步。采用台式机版前备份本机草稿，备份可明确恢复为共享版。

提示词编辑器另行保护未保存草稿：远端保存版本变化时保留当前草稿，选择最新规则或保留草稿后才能保存。宿主冲突处理若断网，状态显示不可用但选择入口继续保留，重连后可继续解决，不把断网当作已解决冲突。

没有共享副本时，有实际模型/服务或自定义提示的本机配置可建立初始副本；空白默认来源不能覆盖已存在的副本。加密文件损坏、加密环境或网关不可用时保留本机设置并报告不可用，不自动创建默认文件。宿主文件锁超时同样报错，不擅自清除其他进程的锁。

旧网址能打开时，在那个来源选择“保留本机配置并同步”迁移。新页面不能读取另一个来源的 localStorage。若旧入口或笔记本不可访问，不能声称已找回其旧提示词和密钥。
