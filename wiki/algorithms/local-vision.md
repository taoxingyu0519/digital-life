# 本地视觉与持续身份算法

核对日期：2026-10-05。范围：当前模型流水线与身份规则。关联任务：AIRI-008、AIRI-009、AIRI-011、AIRI-014、AIRI-025。

摄像头 JPEG 在主机 Python 服务中推理。模型负责提取候选，规则负责持续确认、姓名归属和学习资格。
下列数值来自当前源码，是工程参数，不是本机准确率或节能测量。

## 检测与动作

| 步骤 | 当前实现 | 输出和限制 |
| --- | --- | --- |
| 物体检测 | YOLOX，等比缩放填充到 640×640，解码 stride 8/16/32 | 类别、边框和置信度。过滤大于 0.25，NMS 阈值 0.45 |
| 人体跟踪 | supervision.ByteTrack | 短时 track_id。轨迹不是永久人物身份 |
| 人脸检测 | OpenCV YuNet | 单张脸位置和关键点。多人歧义阻止归属 |
| 人脸特征 | 本机 EdgeFace S 提取 512 维向量，SFace 负责对齐与 128 维登记 | 按模型版本使用独立本地索引 |
| 动作提示 | MediaPipe Face 与 Hand，加 temporal.py 时间规则 | 可见动作。动作不证明情绪或意图 |

ByteTrack 的核心关联由已安装 supervision 实现。本项目在 Runtime 中配置 frame_rate=15 和 lost_track_buffer=15。
这些配置值不证明实际摄像头恒定十五帧。追踪内部细节需继续读依赖实现。

## 质量分级

face_sample 拒绝最短边小于 64 像素的人脸、多个脸和空裁剪。
Laplacian 方差小于 35、灰度均值不在 40 到 220 之间，或鼻眼偏移超过 0.6，也拒绝。
人脸特征只在对齐后生成。EdgeFace 输入为 RGB、112×112，归一化到 −1 至 1。

最短边至少 96、清晰度至少 70、偏移绝对值至多 0.45 的帧可用于入库。
其余已通过基础检查的帧只用于识别。这样短时模糊不会污染登记模板。

## 识别与保持

向量按 L2 范数归一化。每个人的得分取当前向量与该人物全部模板的最大余弦相似度。
首次确认要求最高得分至少 0.55，且与第二名的差至少 0.10。
SFace 有效校准可以提高这两个阈值，不能将它用于 EdgeFace。没有校准也可进行普通社交识别。
最近两秒内至少三次一致候选才确认。采样间隔至少 0.25 秒。

已确认轨迹在两秒内可用保持阈值 max(0.50, 首次阈值−0.05)。候选仍需唯一且人物不变。
model.py 对短时模糊另设最多 1.5 秒的缓存。多人、冲突和证据超时撤销确认。
检测漏人时只保留内部短时证据，不输出不存在的人，也不把那时的发言归给旧人物。
这些规则改善连续性，真人误认与姓名跳变仍由 AIRI-009 验收。

## 多帧证据与特征调度

recognition.py 保留最多四次、两秒内的同人物得分。清晰帧权重为 1，识别专用帧权重为 0.35。
当前帧必须独立支持同一个唯一人物，才参与平均。陌生、歧义和换人清空历史，不能用旧高分恢复姓名。
这使用有界加权规则，没有部署完整 CAFace 网络。

摄像头和 ByteTrack 持续运行，人脸可见性与质量检查最多每秒五次。
检查同时输出当前归一化人脸框，身份未知或登记质量不足不阻止位置跟随。
最多缓存 300ms 的同轨迹位置，失脸或重叠清空。前端跟随再作更严格的 500ms 画面年龄校验。
确认后，小尺寸灰度裁剪变化低于 0.08 时，特征约每秒提取一次。
新轨迹、外观变化和认识人阶段恢复较高频率。多人、重叠和重置清空证据与裁剪缓存。
metrics 返回实际模型、提取与跳过次数。减少人脸特征调用不等于相同比例整机节能。

本机对齐裁剪对比中，SFace、EdgeFace XS、S 单次中位耗时分别为 6.29、2.22、3.26 毫秒。
S 在三个已有角度上的最低相似度更高，因此本机选择 S。小样本不能确定真人误认率。

## 自然建档

social.py 用规则提取真实用户的自我介绍。它只消费真实文字或最终转写，不消费助手猜测。
候选姓名先复述确认。字词替换或完整姓名修正后重新确认，沉默、普通聊天与超时不能当确认。
行为记忆指导话术，程序状态保护写库。未确认时不触发登记采样或高频学习特征提取。
确认后改名使用原人物 ID，照片和交流记忆保留。旧档案再次相遇补问一次文字确认。
同一清晰单人轨迹收集至少十个一致样本，采样间隔至少 0.4 秒。
明确介绍登记时可保存 front、left、right 人脸裁剪。已认识人物的新条件经轨迹复核进入独立扩展，不再单帧补基础照片。

新样本与已有模板逐样本比较。最高候选的中位相似度至少 0.90、最低至少 0.85，才可复用已有档案。
若次高候选相差不足 0.10，则拒绝歧义合并。仅姓名相同不能合并人物。
姓名纠正、人物变化、多人和拒绝记忆都会影响学习状态。人物模板与新模型向量不能混用。
