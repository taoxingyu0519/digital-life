# 开发经验与可复用知识

核对日期：2026-10-03。来源为已有任务与源码修复，关联 AIRI-009、010、011、012、013、016、017、018。

## 服务状态与现场行为

模型 ready 只证明模型加载。摄像头连接、帧处理、主动调度和语音输出分别需要证据。
普通输入开关代表用户偏好，不等于正在说话或占用实时会话。AIRI-032发现它阻塞主动接通，而实时通话已有普通 ASR 暂停机制。排查“只有文字”先核对自动启动门控，再分别验证网关返回音频与客户端播放。见[报告](../../airi/docs/ai/reports/2026-10-08-active-mode-voice.md)。
排查先看当前进程和指标，再看界面。旧日志不能证明当前服务版本。
证据：[本地运行](../modules/local-runtime.md)、[主动社交 ADR](../../airi/docs/ai/adr/2026-09-30-active-social-companion.md)。

## 异步生命周期

麦克风授权和模型回复可以长时间等待。摄像头恢复必须使用独立维护时钟。
同一次问候的状态监听只比较人物、模式和会话标量。每个新帧对象变化会误取消合法工作。
generation 与取消控制器共同阻止停止后的迟到输出。
证据：[companion.ts](../../airi/packages/stage-ui/src/stores/companion.ts)、[local-vision-runtime.vue](../../airi/apps/stage-web/src/components/local-vision-runtime.vue)。

## 流式转写语义

增量、累积假设和最终结果不是同一种事件。
累积内容重复追加会污染姓名提取并制造重复档案。完整和最终内容必须替换。
证据：[doubao.ts](../../airi/packages/realtime-voice/src/doubao.ts)、[social.py](../../airi/services/local-vision/social.py)。

## 连续识别与数据质量

首次确认与短时保持承担不同目标。单一阈值容易在模糊时反复抹去姓名。
适用于识别的帧不自动适用于登记。清晰度不足的样本不能更新照片或模板。
同名不证明同人。档案复用依赖唯一且充分一致的人脸样本。
多帧平滑必须要求当前帧独立支持同一人物，否则旧高分会掩盖陌生人。
改用新模型时保留人物资料，独立建立模型索引。特征维度、版本和校准不能混用。
降低稳定脸特征频率时继续质量与可见性检查，检测到变化立即恢复采样。
识别与注视有不同门槛。可见脸即能成为目标，不能让身份确认或登记质量阻塞目光。
角色头部偏移在动画后叠加，下一帧先恢复原姿态，否则会逐帧积累。
持续摄像头目标不能使用鼠标静止超时。跟随要按采集代际和实际帧年龄释放。
证据：[视觉算法](../algorithms/local-vision.md)。

## 网络安全上下文与设备归属

LAN HTTPS 可以提供安全上下文。只允许 localhost 的检查会错误拒绝合法笔记本。
浏览器设备属于访问端，模型推理属于主机。设备故障和主机推理故障需分别定位。
整个测试网址无法连接时，先核对主机当前监听端口。2026-10-01 的故障由主机服务停止导致，
恢复既有启动入口后原链接与证书继续有效；没有取得停止触发原因的证据。
进程记录文件只用于核对进程身份，不能替代实时端口和 HTTPS 请求验证。
证据：[LAN 指南](../../开发文档/08-lan-testing.md)。

AIRI-030：DHCP 地址变化后，旧地址的监听记录不能证明当前网络可达。
SSH、UU 映射目标和防火墙本机地址必须与实际网卡地址一致。UU 映射到主机回环 SSH 后可避开家庭 IP 漂移。
服务恢复不能同步等待前台长驻 Web。把服务生命周期与恢复命令分开，再核对真实健康回执。
公司 SSH/页面成功、家庭 LAN 成功、摄像头/模型通话成功分别记录，不用某一项代替其他验收。

## 验证边界

合成 JPEG 可以证明协议、推理和清理，却不能证明真人识别准确率或耗电。
已有裁剪回放可检验重启后档案匹配，却不能确定真实换人误认率。
现场采样处理帧数没有增长时，零跳变表示没有样本，不能证明稳定。
单元测试通过不等于真实上游 API 兼容。论文指标不等于 Windows 本机性能。
既有会话浏览器测试的挂载与网络模拟问题单独保留 AIRI-012。
证据：[变更记录](../../项目管理/变更记录.md)、[视觉验证说明](../../开发文档/07-local-vision.md)。

## 快慢脑与协议投递

前台会话、代码调度、后台执行是不同职责。工具受理不要等待模型结果，否则全双工会变成同步等待。
用户继续闲聊不等于任务已取消。版本与来源轮次必须显式保留；状态入上下文不自动授予发言权。
生成完成、音频完成、本地播放完成是三个时刻。被打断但未听到的尾句不能当已确认事实。
AI整理的协议示例需核对官方实际消息。豆包extension在顶层，session.update完整覆盖，FC读取items批次。
“输入文字”要区分朗读稿和用户提问。实测speech_text_buffer.commit只回音频，不能因为Qwen映射相同就声称文字问答已通；文字请求交已配置慢脑，已知朗读稿补本地转写后仍等播完确认。
有界结构化结果应裁剪字段或条目后再序列化，不能直接截断JSON字符串。
证据：[快慢脑专题](../modules/fast-slow-brain.md)、[正式ADR](../../airi/docs/ai/adr/2026-10-02-fast-slow-brain.md)。

## 模型与联网工具

模型名称、深度思考开关与网页检索能力是不同事实。API可达也不证明有搜索工具。
检查厂商具体协议，再查请求工具列表、执行状态和来源。输入兼容web_search_tool_result不代表应用执行了检索。
快脑原生搜索配置不会自动进入慢脑；文字路由必须独立验收。提示词和关键词判断不能代替真实搜索。
证据：[联网核对报告](../../airi/docs/ai/reports/2026-10-03-search-capability.md)，AIRI-017。

Codex安装skill不自动给AIRI增加工具。运行时需要独立实现真实接口、权限门控、模型函数调用与结果投递。
匿名免费入口与免费账户月额度不同，不能伪造剩余额度或给匿名用户承诺账户配额。记录服务端消耗和来源，额度错误保持失败。
首次调用也需先解析工具再构建配套prompt，避免有工具无指导；实际服务联网与模拟模型链路分别验收。
官方CLI匿名搜索可用不意味着反馈也匿名可用：本轮反馈要求登录，未声称已发送或退款。
证据：[Firecrawl接入报告](../../airi/docs/ai/reports/2026-10-03-firecrawl-search.md)，AIRI-018。

## 搜索拒绝与账户状态

匿名REST偶尔成功不能证明浏览器直连是厂商长期支持的入口。使用官方明确支持的CLI/SDK/MCP协议，不伪造客户端身份。收到403应保留脱敏正文；没有正文不能猜是IP、额度或WAF，也不能据搜索失败说整机离线。余额数字不能证明Free套餐或自动充值关闭。配置变化后，迟到的响应不得影响新配置；共享错误状态可阻止模型连续换词重复请求。证据：[403修复](../../airi/docs/ai/reports/2026-10-03-firecrawl-403-fix.md)，AIRI-020。

快脑有通用委托工具不等于它知道后台能做哪些工作。前台能力提示应来自后台实际工具门控，不能因前台原生搜索关闭就声明整个系统离线。长连接中配置会变化，提示与工具列表必须同步更新；不能只在session.create时生成。文字直接派发成功与语音模型选择派发分别验证，模拟边界只证明工程闭环。证据：[语音联动修复](../../airi/docs/ai/reports/2026-10-03-voice-slow-brain-link.md)，AIRI-021。

## 语音投递与播放缓存

工具移交必须释放前台生成占用；两个缺失任务ID相等不能作为取消依据。受理语和结果应由一条路径发声，待播稿同时进入模型生成与直接朗读会产生重复。真实豆包chat_tts_text开始/结束有响应ID，分片和response.done的编号结构不同；后者不能代替相关音频完成。TTS快于播放时，超过十秒是正常突发，应缓存并分段调度，真正的格式、空音频与有界溢出才失败。面板状态变化使用悬浮层，不占角色和输入区布局。证据：[播报修复](../../airi/docs/ai/reports/2026-10-03-voice-delivery-fix.md)，AIRI-022。

## 会话计划与事实稿

会话计划必须对照当前工程。已有任务版本、单worker、唯一发声路径不重复建设；表达策略要进入实际请求才生效。不要用关键词假装理解情绪，也不要把工程等待时间包装成心理学阈值。摘要与建议稿可以互相矛盾，直接使用同一口语摘要能避免二次改写，但不能证明模型结论真实。播放中断只说明该段未确认，不表示任务被取消；已确认分段与未确认分段分开，恢复需用户明确要求。证据：[会话策略改进](../../airi/docs/ai/reports/2026-10-04-fast-conversation-policy.md)，AIRI-023。

## 跨对话知识维护

姓名确认习惯可以保存为行为规则，但确认状态和数据库写入必须独立执行。
改名绑定持久人物 ID，不根据新姓名创建第二份档案。普通否定意见不能触发纠错状态。
管理界面隐藏内容不等于鉴权，维护 API 必须在服务端和排队执行前检查会话。
姓名和人脸是社交证据，不是开发者账号认证。见[姓名与记忆报告](../../airi/docs/ai/reports/2026-10-05-memory-management.md)，AIRI-025。

目录清单说明“有什么文件”。人工专题说明“谁负责、数据如何流动、为什么如此”。
源码指纹只能提示变化，不能证明结论正确。复核必须读相关变更，再显式更新证据。
开发结论写入文件和任务后，下一对话才有可读取的持久依据。
证据：[维护流程](../maintenance.md)。

## 识别账户必须与采集生命周期分开

AIRI-034：身份切换会触发会话切换。如果会话选择又销毁摄像头，确认人物会立刻丢失证据并退回陌生人，形成循环。采集保持连续，会话只重置投影；身份按短租期失效。历史用持久人物 ID 分区，姓名仅用于显示。

同步测试要安装真实 Pinia 和组件上下文，异步重入绑定原 Pinia 实例。原生浏览器需清理测试域名的 IndexedDB 与视觉夹具；跨文件残留可制造重复历史或未确认姓名。云连接拥有权用本机原生 WebSocket 验证，而不是用导入 mock 的调用次数代替。见[交付报告](../../airi/docs/ai/reports/2026-10-09-face-stage-accounts.md)。

## 话痨是应用事件，不是假用户轮次

主动续聊要核对最终厂商请求。core-agent的context authority会投影为user，仅源代码type写system不能证明没有假用户消息。本轮用明确的应用system包络传递引用数据，并断言实际请求所有messages的role。生成内容、候选发言和实际播放事实仍分开。
浏览器IndexedDB会跨Pinia fixture保留历史。新增连续播报测试须创建独立会话，而不是误把前一个测试的记录当当前输出，或删除持久库掩盖真实隔离行为。
风格和授权视觉变化必须同时取消准备与旧片段发声，避免撤回授权后迟到稿仍播出。见[话痨开发记录](sessions/2026-10-04-chatty-conversation.md)。

## 人设提示必须接入措辞作者

续聊失效不能比较整份动态观察。时间、动作、物体变化属于新数据，授权或相遇变化属于权限边界，必须分开。否则持续摄像头会饿死合法生成，增加超时也无效。
UI门控读取的活动结果和播放状态必须响应变化，否则真实交付已完成，缓存状态还会阻止续聊。扩展提示后要验证完整网关长度，保留JSON结构而不是裁断末尾。
无回应是计时事实，不是用户心理事实。程序负责已听计数和试探机会，模型考虑措辞与主题匹配，不把猜测写成长期偏好。见[AIRI-027报告](../../airi/docs/ai/reports/2026-10-06-chatty-idle-and-reflection.md)。

固定句子交给TTS直接朗读时，模型系统提示不会改写它。先定位谁拟定措辞，再调整对应生成请求。
快脑拟定工具受理与等待稿，慢脑拟定确认结论，运行时负责真实受理、版本、发声与送达。
续聊错误不能全部压成一个布尔值。保留安全的HTTP状态、类别和等待时间，避免把服务拒绝说成断网。
旧错误没有保存时必须承认无法追溯。参见[AIRI-026报告](../../airi/docs/ai/reports/2026-10-06-chatty-preparation-and-persona.md)。

AIRI-028：等待计时没有捕获私人数据，草稿已经捕获，两者不能使用相同的视觉撤权取消范围。首次问候须复用单一语音槽位，不能以防双循环为由全部跳过。
AIRI-029：候选不能证明自己，自动扩展不能启动下一轮学习。基础库须冻结审核版本，候选来源可追溯且能独立撤销。真实编码器构造增益不等于真人泛化准确率，轨迹编号不是实名身份。

AIRI-031：UU 设备在线、普通远控成功、远程终端可执行、SSH 隧道建立、笔记本网页可用是不同证据。
远程终端提示升级时，还要核对官网实际安装包版本；同版本不能证明重装会修复协议错误。
台式机自身 HTTP 200 和视觉 ready 不能代替笔记本的本机入口检查。
见 [主动连接现场边界](../../开发文档/08-lan-testing.md#7-从台式机主动连接笔记本的现场边界airi-031)。


AIRI-033：保存按钮成功不能证明模型使用新规则。分别验证草稿、持久重读、序列化模型请求及旧版本迟到稿。
中文默认值与编辑器集中管理，输出协议由运行时持有。TTS朗读的措辞作者仍决定哪一侧提示词生效。

AIRI-035：聊天页面可关闭，模型工具仍须直接访问同一持久服务。界面分页不能冒充数据库分页，时间缺失不能用会话更新时间补造。测试需验证实际序列化工具和工具回路；注解删除要覆盖原聊天页等所有入口，并用相同锁阻止并发整理遗留。框架模拟隐藏了身份 store 接线问题，旧会话契约改用真实 Pinia refs，只保留输入与 IO 边界。

AIRI-036：同会话快照重建引用不等于账户或代际变化，通信watcher逐项比较实际归属值。附加历史IO须有等待上限及迟到结果隔离，不把存储失败当成网关失败。恢复后清理旧错误需单独回归。见[语音与入口修复](sessions/2026-10-11-voice-and-settings-regression.md)。

## 启停必须覆盖所有重新分配入口

AIRI-037：普通输入、历史重试和工具重跑都能产生请求，休眠门控须落在共同执行入口，并在修改原记录前拒绝。不能只隐藏通话按钮。资源释放还需取消自动维护、停止后迟到IO及服务器无绑定栅栏。

持久设置的外部storage监听会让跟随窗口提交旧快照，覆盖领导窗口的休眠；真实双窗口同步测试发现后关闭监听，统一由action持久化。多个页面更新时旧领导窗口可能缺少新action，应显示刷新提示并保留设置入口。

交付门禁固定保留旧功能、失败即阻止通过声明；文件顺序执行避免本机测试资源争抢。实际页面还发现空背景颜色引发整页异常，使用真实Color.js先复现再修复。构建不代表运行进程已更新，配置连接不代表真人通话。见[本轮记录](sessions/2026-10-11-stage-runtime-and-delivery.md)。
