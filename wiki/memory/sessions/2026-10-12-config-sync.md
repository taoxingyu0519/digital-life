# 笔记本与台式机配置同步记录

日期：2026-10-12（Asia/Shanghai）。任务：AIRI-039。范围：Web 配置共享、迁移保护与交付基线。

## 目标与结果

用户反馈修复连接并登录后，笔记本提示词与慢脑模型像被重置，希望各入口修改同一配置。连接助手说明确认新入口为4173；源码确认旧设置按浏览器来源保存。本轮新增台式机加密副本与设置页，保留离线编辑/备份/CAS冲突，补齐角色卡持久化和登录默认值后的慢脑恢复。

配置共享不等于聊天档案或人脸账户共享，也不替代 hosted 鉴权。本轮不修改笔记本连接助手，不添加外部账户。边界见 [配置同步](../../modules/shared-config.md)。

## 依据与决策

采用已有 SSH 与同源入口，而不新建云账户。所有设备使用同一台式机副本；过期整体配置明确冲突，不凭时钟或“最后到达”覆盖。空白新来源不能代替已有配置。API Key 用现有 Windows DPAPI，进程参数与报告不含正文。真实 Vue/Pinia/浏览器和真实隔离 DPAPI 文件分别验证，不模拟框架。

浏览器 speech 适配器会由初始化自动注册，不能因此制造新的共享版本或替换设备语言选择。登录 provider 也不能上传。模型选择必须同时写卡和运行时，否则 UI 同步成功后，刷新仍会读旧卡。

## 验证与边界

固定门禁继续执行全部旧基线，加13项浏览器和6项主机回归；12步门禁通过、自动用例合计267项。本轮实际双来源保存/反向恢复/刷新，以及启停循环和休眠设置/长期记忆导航完成。最终统计、Wiki核对和不可用设备详见 [中文报告](../../../airi/docs/ai/reports/2026-10-12-config-sync.md)。日志位于工作区 `.runtime/delivery/AIRI-039`。

本机4173仅为验收时的临时 TCP 转发，模拟 SSH 的字节转发和 Host 保留；不能称为真实笔记本或公司网络测试。旧笔记本设置未直接读取，恢复方式保留给旧来源使用；不保证已找回旧值。真实慢脑未配置，浏览器未发现摄像头，真人音频与旧入口恢复待现场验收。

## 可复用经验

先核对网页 origin，再判断设置删除。上线共享配置须同时验证源缓存、远端版本、断线重载、选主交接和当前角色卡，不能只检查保存按钮。HTTP错误分支先完成读取再写成功响应头，损坏文件才能返回明确503。

远端已保存配置与正在编辑的草稿是不同版本。回归先复现草稿被轮询覆盖，再保留草稿、明确解决冲突后才保存；断网不能移除冲突处理入口。登录默认模型与角色卡持久选择也须同时验证，防止刷新后读取旧卡。
